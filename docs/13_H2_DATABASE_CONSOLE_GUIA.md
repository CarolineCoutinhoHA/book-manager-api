# 🗄️ H2 DATABASE CONSOLE - GUIA COMPLETO

## 🎯 O QUE É H2 DATABASE?

H2 é um banco de dados em memória, perfeito para desenvolvimento e testes.

### Características do H2
- ✅ **Em memória** - Dados são perdidos ao reiniciar aplicação
- ✅ **Rápido** - Sem I/O de disco, muito veloz
- ✅ **Zero configuração** - Funciona out-of-the-box
- ✅ **Console web** - Interface gráfica para visualizar dados
- ✅ **SQL padrão** - Suporta comandos SQL normais
- ✅ **Compatível** - Simula outros bancos (MySQL, PostgreSQL)

## 🏗️ ESTRUTURA DO BANCO

### Tabelas Criadas Automaticamente
```sql
-- Tabela de Autores
CREATE TABLE autor (
    id_autor BIGINT GENERATED BY DEFAULT AS IDENTITY,
    cep VARCHAR(255) NOT NULL,
    disponibilidade BOOLEAN NOT NULL,
    email VARCHAR(255) NOT NULL,
    nome VARCHAR(255) NOT NULL,
    telefone VARCHAR(255),
    uuid UUID NOT NULL,
    PRIMARY KEY (id_autor)
);

-- Tabela de Livros
CREATE TABLE livro (
    id_livro BIGINT GENERATED BY DEFAULT AS IDENTITY,
    categoria TINYINT NOT NULL CHECK (categoria BETWEEN 0 AND 4),
    data_de_publicacao DATE NOT NULL,
    disponibilidade BOOLEAN NOT NULL,
    isbn VARCHAR(255) NOT NULL,
    titulo VARCHAR(255) NOT NULL,
    uuid UUID NOT NULL,
    PRIMARY KEY (id_livro)
);

-- Tabela de Usuários (JWT)
CREATE TABLE usuario (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY,
    username VARCHAR(255) NOT NULL,
    password VARCHAR(255) NOT NULL,
    role VARCHAR(255) NOT NULL,
    PRIMARY KEY (id)
);

-- Tabela de Relacionamento Many-to-Many
CREATE TABLE "livro-autor" (
    autor_id BIGINT NOT NULL,
    livro_id BIGINT NOT NULL,
    PRIMARY KEY (autor_id, livro_id)
);
```

## 📊 QUERIES ÚTEIS PARA DESENVOLVIMENTO

### 1. Verificar Dados Básicos
```sql
-- Ver todos os autores
SELECT * FROM autor;

-- Ver todos os livros
SELECT * FROM livro;

-- Ver todos os usuários
SELECT * FROM usuario;

-- Ver relacionamentos livro-autor
SELECT * FROM "livro-autor";
```

### 2. Queries com JOIN
```sql
-- Livros com nomes dos autores
SELECT 
    l.titulo,
    l.isbn,
    a.nome as autor_nome
FROM livro l
JOIN "livro-autor" la ON l.id_livro = la.livro_id
JOIN autor a ON la.autor_id = a.id_autor;

-- Autores com quantidade de livros
SELECT 
    a.nome,
    a.email,
    COUNT(la.livro_id) as total_livros
FROM autor a
LEFT JOIN "livro-autor" la ON a.id_autor = la.autor_id
GROUP BY a.id_autor, a.nome, a.email;
```

### 3. Filtros e Buscas
```sql
-- Autores ativos (disponibilidade = true)
SELECT * FROM autor WHERE disponibilidade = true;

-- Livros por categoria (0=LITERATURA, 1=CIENCIA, etc.)
SELECT * FROM livro WHERE categoria = 0;

-- Buscar autor por email
SELECT * FROM autor WHERE email = 'machado@literatura.com';

-- Buscar livro por ISBN
SELECT * FROM livro WHERE isbn = '978-85-359-0277-5';
```

### 4. Estatísticas
```sql
-- Total de registros por tabela
SELECT 'Autores' as tabela, COUNT(*) as total FROM autor
UNION ALL
SELECT 'Livros' as tabela, COUNT(*) as total FROM livro
UNION ALL
SELECT 'Usuários' as tabela, COUNT(*) as total FROM usuario;

-- Livros por categoria
SELECT 
    CASE categoria
        WHEN 0 THEN 'LITERATURA'
        WHEN 1 THEN 'CIENCIA'
        WHEN 2 THEN 'BIOGRAFIA'
        WHEN 3 THEN 'FANTASIA'
        WHEN 4 THEN 'MISTERIO'
    END as categoria_nome,
    COUNT(*) as total
FROM livro
GROUP BY categoria;
```


### 2. Atualizar Dados
```sql
-- Atualizar email de um autor
UPDATE autor SET email = 'novo@email.com' WHERE id_autor = 1;

-- Marcar livro como indisponível (soft delete)
UPDATE livro SET disponibilidade = false WHERE id_livro = 1;

-- Atualizar categoria de um livro
UPDATE livro SET categoria = 1 WHERE titulo = 'Dom Casmurro';
```

### 3. Deletar Dados
```sql
-- Deletar relacionamento livro-autor
DELETE FROM "livro-autor" WHERE livro_id = 1 AND autor_id = 1;

-- Deletar autor (cuidado com foreign keys)
DELETE FROM autor WHERE id_autor = 1;

-- Limpar tabela completamente
DELETE FROM "livro-autor";
DELETE FROM livro;
DELETE FROM autor;
```

### 4. Verificar Constraints

## 🔧 TROUBLESHOOTING

### Problema: Console não carrega
```
Soluções:
1. Verificar se aplicação está rodando (./gradlew bootRun)
2. Confirmar URL: http://localhost:8080/h2-console
3. Verificar se h2.console.enabled=true no application.properties
4. Tentar em navegador diferente (modo incógnito)
```

### Problema: Erro de conexão
```
Soluções:
1. JDBC URL: jdbc:h2:mem:bookdb (exatamente assim)
2. User Name: sa (não deixar vazio)
3. Password: (deixar vazio)
4. Verificar se banco foi criado (rodar aplicação primeiro)
```

### Problema: Tabelas não aparecem
```
Soluções:
1. Verificar se aplicação criou as tabelas (logs do Hibernate)
2. Executar algum endpoint da API primeiro
3. Verificar ddl-auto=create-drop no application.properties
4. Restartar aplicação se necessário
```

### Problema: Dados desaparecem
```
Explicação:
- H2 é em memória (dados são perdidos ao reiniciar)
- Comportamento normal para desenvolvimento
- Para persistir dados, usar H2 em arquivo ou outro banco
```

## 📈 MONITORAMENTO EM TEMPO REAL

### 1. Acompanhar Inserções
```sql
-- Executar periodicamente para ver novos dados
SELECT COUNT(*) as total_autores FROM autor;
SELECT COUNT(*) as total_livros FROM livro;

-- Ver últimos registros inseridos
SELECT * FROM autor ORDER BY id_autor DESC LIMIT 5;
SELECT * FROM livro ORDER BY id_livro DESC LIMIT 5;
```

### 2. Verificar Relacionamentos
```sql
-- Ver quantos livros cada autor tem
SELECT 
    a.nome,
    COUNT(la.livro_id) as total_livros
FROM autor a
LEFT JOIN "livro-autor" la ON a.id_autor = la.autor_id
GROUP BY a.id_autor, a.nome
ORDER BY total_livros DESC;
```

### 3. Validar Integridade
```sql
-- Verificar se há registros órfãos
SELECT 'Livros sem autor' as problema, COUNT(*) as total
FROM livro l
LEFT JOIN "livro-autor" la ON l.id_livro = la.livro_id
WHERE la.livro_id IS NULL

UNION ALL

SELECT 'Relacionamentos inválidos' as problema, COUNT(*) as total
FROM "livro-autor" la
LEFT JOIN livro l ON la.livro_id = l.id_livro
LEFT JOIN autor a ON la.autor_id = a.id_autor
WHERE l.id_livro IS NULL OR a.id_autor IS NULL;
```
